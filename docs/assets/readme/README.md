# README artwork (constellation design v2)

The pictures in the root [`README.md`](../../../README.md) are generated by
[`generate.py`](generate.py) from this repository's facts, so they cannot drift
from the code and docs they describe.

```bash
python3 docs/assets/readme/generate.py          # rewrite the SVGs beside this file
python3 docs/assets/readme/generate.py --check  # read-only drift gate (exit 1 on drift)
```

Standard library only; output is deterministic (a seeded starfield, no
timestamps, no remote assets, no external fonts), so a re-run is byte-identical.

## Files

| File | Where it is used |
| :--- | :--- |
| `hero.svg` · `hero-mobile.svg` | Banner: a document cut into windows, a shared encoder, six heads and a calibrated gate. The mobile twin is a vertical layout for phones |
| `stats.svg` · `stats-mobile.svg` | "By the numbers" strip; every figure is backed by the README or the source |
| `flow.svg` · `flow-mobile.svg` | The process as a chain of cards with a travelling particle and a side row |
| `constellation.svg` · `constellation-mobile.svg` | Data-flow map of the Mailroom constellation with this repository marked "you are here" |
| `tui.svg` | Terminal dashboard (gauges and a log tail) in the same style as the Digital-Mailroom README |
| `terminal.svg` | Self-typing quickstart terminal |

Wide SVGs are served through `<picture>` with a `(max-width: 640px)` source that
swaps in the mobile twin.

## How it is built

- [`_art.py`](_art.py) is the shared kit. It is **identical in every constellation
  repository** (llm-mailroom, llm-dojo-scoring, Mailroom-Corpus-EDA, mailroom-ml);
  change it in all of them or in none.
- `generate.py` holds only this repository's labels, scene and source-backed facts.
- Meaning lives in static elements. Everything that merely moves (twinkling stars,
  travelling particles, shine sweeps, the terminal cursor and spinner) is inside a
  `.motion` group that `@media (prefers-reduced-motion: reduce)` hides, so a
  reader who asks for less motion still gets every label and number.
- Colours come from the constellation palette. A project outside the constellation
  should keep its own palette and layout rather than reuse this kit's.

## Changing the artwork

1. Edit `generate.py` (facts and labels) or, for all repositories at once, `_art.py`.
2. Run `python3 docs/assets/readme/generate.py`.
3. Look at the SVGs in a browser at desktop and phone width, and check that no text
   overflows its card.
4. Commit the sources and the regenerated SVGs together; `--check` must pass.
